아이가 영상 볼 때 화면을 못 누르게 하는 방법 (안드로이드)

아이에게 영상을 보여 주면 대개 이렇게 끝납니다. 작은 손이 영상을 멈추거나, 다른 영상을 열거나, 광고를 누르거나, 앱을 나가 버리죠. 안드로이드 폰과 태블릿에서 이걸 막는 방법은 세 가지입니다.

1. 앱 고정 (안드로이드 기본 기능)

설정에서 앱 고정을 찾으세요. 보통 보안 메뉴 안에 있고 이름은 기기마다 조금씩 다릅니다. 앱을 고정하면 폰이 그 앱 안에 머물러 아이가 앱을 나갈 수 없습니다. 앱 안의 터치는 그대로라 영상을 멈추거나 바꾸는 것까지 막지는 않습니다.

2. 상호작용 제어 (일부 삼성 갤럭시)

일부 갤럭시에는 설정 › 접근성 › 상호작용 및 손재주 안에 상호작용 제어가 있습니다. 화면 전체나 일부의 터치를 막고, 한 번 정해 둔 단축키로 켭니다.

3. 터치 잠금 (한 번 탭, 모든 안드로이드)

  1. 터치 잠금을 열고 시작을 누르면 화면 위에 작은 자물쇠 버튼이 뜹니다.
  2. 영상을 틀고 버튼을 한 번 탭하면 화면 전체 터치가 잠기고, 영상은 그대로 재생됩니다.
  3. 잠긴 화면을 두 번 톡톡 누르면 풀립니다.

터치 잠금 Pro(1회 결제)는 이중탭을 익힌 아이를 위해 PIN 해제와 보호 모드를 더합니다. ‘다른 앱 위에 표시’ 권한만 쓰고 개인정보를 수집하지 않습니다.

무엇을 쓸까

  • 아이가 한 앱 안에만 있게 하려면: 앱 고정
  • 설치 없이 갤럭시에서 터치를 막으려면: 상호작용 제어
  • 어떤 안드로이드든 한 번 탭으로 잠그고 바로 풀려면: 터치 잠금
